# Membership ladder

Four named tiers each own a movable benefit array. Their reductions form a
monotonic ladder: raising a lower tier above any higher tier updates the rest of
the ladder in the same transaction, so the form never exposes a contradictory
intermediate value.

## Try the complete flow

Raise the Seed reduction above the other tiers and watch the preview cascade.
Add and move benefits independently inside every tier. Connect the selected
workspace through a fake mutation, then add a pause window from the calendar
shortcuts and edit its dates in the generated array.

## What this form stresses

- Four nested arrays under fixed object paths.
- One object-scoped fragment that expands relative tier paths without casts.
- `extendValueChanges` normalizing several correlated fields atomically.
- Cross-tier schema validation as a second line of defense.
- Query-provided workspace options and connect/disconnect mutations.
- A custom calendar surface using typed array commands.
- Date-range validation and stable pause-window row identity.
- A derived benefit count in the typed submission output.
