# Persistence

Use persistence when a form draft must survive a remount, navigation, or
server round trip. Form, Please owns encoding, hydration, scheduling, and
restore validation. Your application owns the storage transport.

## Hydration lifecycle

Construction starts in the `"idle"` phase. Call `restore()` before local
editing. A successful or empty restore changes the phase to `"active"` and
starts save scheduling.

If the application skips restore, call `start()`. If restore throws because
stored data is invalid or storage failed, report the error and call `start()`
only when local values should become authoritative.

A local document edit during asynchronous restore produces `"conflict"`.
Persistence keeps the local edit and does not install or overwrite the loaded
document. Resolve the product conflict, then create a new form or choose an
explicit recovery flow.

Restore results are `"applied"`, `"empty"`, `"cancelled"`, `"transformed"`,
`"unavailable"`, or `"conflict"`. Cancellation and transformation come from
application middleware.

## Save state and operations

`getSnapshot()` exposes a phase and save state. Save state is `"idle"`,
`"scheduled"`, `"saving"`, or `"failed"`. The default `saveDelay` is `500`
milliseconds and restarts after each document commit.

- `flush()` saves pending data immediately and requires active persistence.
- `clear()` cancels the timer and removes the stored value.
- `subscribe(listener)` reports phase and save-state changes.
- `onError(error)` reports codec, adapter, and background save failures.

A storage failure does not roll back the form commit. Catch explicit operation
errors. Use the failed save state to offer Retry, Save now, or Download draft.

## Encoding, codecs, and migration

The canonical envelope stores a protocol identifier, protocol version,
application version, mode, and structural payload. It preserves `undefined`,
arrays, objects, and finite JSON scalars. Unsupported values fail with their
canonical form path.

Use `createDateCodec()` for `Date`. Use `createFileCodec()` only when storing
file bytes is appropriate. The file codec defaults to a 10 MiB limit and
requires the browser `File` API. Codec tags must be non-empty and unique.

Provide `migrate` when the stored application version differs:

```ts

```

Migration receives untrusted JSON after envelope validation. The returned JSON
is decoded, normalized, and validated against the current schema before live
restore. A failed migration leaves the live document unchanged.

## What persistence does not restore

Persistence does not restore touched paths, issues, validation or submission
state, runtime context, focus targets, subscriptions, callbacks, or runtime
options. Hydration bypasses value policies, lifecycle hooks, item defaults,
automatic validation, and mutation callbacks. It still passes through the
open middleware chain.

Read [History and journals](/guides/history) when stored drafts also need undo,
redo, and replay.
