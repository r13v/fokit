## State ownership

History stores an initial checkpoint and committed document events. Each event
changes values and row identity together. History does not store runtime
context, the dirty baseline, touched paths, issues, validation, submission, or
focus state.

Forms without the middleware do not retain checkpoints or events.

## Groups and retention

Consecutive control edits to the same path share a group for `750`
milliseconds by default. A batch is one group. A forwarded blur, path change,
timeout, reset, or restore closes the active group.

Set `groupWindow` in milliseconds to change the time window. Set it to `0` to
disable time-based closure. Set `limit` to a finite non-negative group count to
compact old groups into a checkpoint. A limit of `0` retains no closed groups.
Omit `limit` for unlimited retention.

## Undo, redo, and seek

`undo()`, `redo()`, and `seek(index)` return `"applied"`, `"unavailable"`,
`"cancelled"`, or `"transformed"`.

- `"unavailable"` means that no target exists.
- `"cancelled"` means application middleware rejected the restore.
- `"transformed"` means middleware committed a different document.

Use `getSnapshot()` and `subscribe()` to render `canUndo`, `canRedo`, `index`,
and `length`. Navigation is limited to the latest checkpoint segment.

## Replay, export, and import

`history.export()` returns an immutable in-memory `FormJournal`. Call
`replayJournal(journal, cursor)` to calculate a document without changing a
live form. Pure replay does not run middleware, hooks, schemas, value policies,
validation, or callbacks.

`journal.cursor` for the current position. Use `segment.checkpoint.cursor` to

## Interactions and limits

- A successful `reset(nextValues)` starts a new checkpoint segment.
- Persistence hydration starts a new checkpoint segment when history mode is
  configured.
- A DevTools restore records one history group.
- Application middleware can cancel or replace every live restore.
- `Date` and `RegExp` leaves are detached. Treat `File` and other opaque leaves
  as application-owned immutable values.
- History is in memory. Use [Persistence](/guides/persistence) to store a
  document or the complete journal.
