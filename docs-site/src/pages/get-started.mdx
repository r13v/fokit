# Get started

## Install

Install "Form, Please", TanStack Form, and a Standard Schema library. This example
uses Zod.

```sh
npm install form-please @tanstack/react-form zod
```

React 18 and React 19 are supported peer dependencies.

## Create a form

```tsx
// [!include ~/snippets/profile-form.tsx]
```

Render `<ProfileForm />`. Submit values with an invalid name or email to see
schema issues. After a valid submit, the handler receives the transformed
output, including `slug`.

Import the optional structural stylesheet once if you want baseline spacing:

```ts
import "form-please/layout.css"
```

The native preset is intentionally unstyled. Replace it with your own controls
and slots, or use the Material UI preset.

## Try the interactive lab

The lab adds conditional fields, an editable contact array, reset, live
TanStack Form state, and a diagnostic snapshot of native browser `FormData`.
Submission uses the TanStack values, not that snapshot. Submit the form to see
the transformed output.
