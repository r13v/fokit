# Creative studio policies

This editor treats access windows, safeguards, age rules, equipment, food,
connectivity, and animal access as one policy system. The sections are separate
for comprehension, but they submit as one validated value and share invariants.

## Try the complete flow

Disable early access and its time and fee disappear together. Add, move, or
remove equipment rules loaded from a separate catalog. Enable all-ages access
without the guardian rule, or publish included connectivity below 25 Mbps, to
see cross-section schema issues.

## What this form stresses

- Two independent baseline queries before the form becomes editable.
- Runtime context supplying select options without entering form values.
- Nested conditional policy groups with optional dependent values.
- Native time controls for browser-managed access-window values.
- A stable array of equipment rules with row-level booleans and amounts.
- Form-wide validation that connects decisions from different sections.
- `extendValueChanges` preserving the initiating transaction while typed
  dependent policy paths clear immediately.
- Sequential writes to a policy resource and its public summary.

Request state never becomes an editable field. Fokit owns the policy value;
TanStack Query owns loading and publishing.
