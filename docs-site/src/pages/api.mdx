# API

"Form, Please" adds typed definitions and generated UI around TanStack Form. A
form binding exposes the complete TanStack API as `form.api`.

All examples on this page come from one physical TypeScript file. The
documentation build type-checks that file against the public package entries.

## Entry points

| Import | Capability |
| --- | --- |
| `form-please` | Form kits, control definitions, resource helpers, and shared types |
| `form-please/default-slots` | Accessible structural slots and localization types |
| `form-please/native-controls` | Native control registry and option types |
| `form-please/preset-native` | Ready-to-use native kit |
| `form-please/preset-mui` | Material UI 9 kit factory |

`form-please/layout.css` and `form-please/package.json` are non-JavaScript
exports. There are no compatibility entry points for the retired runtime.

## useForm

`kit.useForm(definition, options)` creates a component-local `FormBinding`.
`defaultValues` must match the schema input. A concrete kit context also
requires `context`. Optional values are `disabled`, `readOnly`, and `onSubmit`.

```tsx
// [!include ~/snippets/api-reference.tsx:use-form]
```

`onSubmit` receives:

- `input`: the editable TanStack Form value;
- `value`: the transformed Standard Schema output;
- `form`: the current binding.

TanStack Form performs the validation parse. After that parse succeeds, Form,
Please parses the same input again to obtain the transformed output. A returned
promise keeps `form.api.state.isSubmitting` true until it settles.

## FormBinding

A binding contains:

- `api`: the typed TanStack `ReactFormExtendedApi`;
- `definition`: the fixed form definition;
- `context`: the current runtime context;
- `disabled` and `readOnly`: current form-wide flags.

The generated focus registry is an implementation detail. Use `form.api` for
field updates, subscriptions, validation, reset, and array operations.

## Form, Fields, Submit, and AutoForm

`kit.Form` provides the binding context and native form semantics.
`kit.Fields` resolves and renders the definition. `kit.Submit` renders the
configured submit slot. These components must be descendants of `kit.Form`.

`kit.AutoForm` composes `kit.Form`, the generated error summary, and
`kit.Fields`. Put `kit.Submit` or other application content inside it as
children.

Use TanStack components directly when the generated tree is only part of the
screen:

```tsx
// [!include ~/snippets/api-reference.tsx:manual-composition]
```

`form.api.Field`, `form.api.FormGroup`, and `form.api.Subscribe` keep their
TanStack Form behavior and types. Application-owned interactive fields must
provide their own labels, descriptions, issue output, and focus behavior.
