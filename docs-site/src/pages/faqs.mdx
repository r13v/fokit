# FAQs

## Why does a valid submit parse the schema twice?

TanStack Form uses the first result for validation. Standard Schema transforms
are not retained in form state, so "Form, Please" parses again to obtain typed
output. This is the TanStack Form recommendation and avoids a custom cache.

## Do hidden fields lose their values?

No. Hidden generated fields do not render, but their values remain in TanStack
Form state.

## How do I use TanStack Form directly?

Use `form.api.Field`, `form.api.FormGroup`, `form.api.Subscribe`, or other
methods on `form.api`.

## Does "Form, Please" fetch async options?

No. Your application owns request and cache state. Pass it through values or
context, then use `matchResource` or `fromResource` in synchronous resolvers.

## Can I replace a definition while a component stays mounted?

No. Treat the definition as fixed for the hook lifetime. Change a React `key`
to remount the form with another definition.
