# Fokit

Fokit is a code-first, schema-validated React form library for teams that want
generated rendering, granular state, and native submission without surrendering
the application design system.

```tsx twoslash
// @jsx: react-jsx
import { createDefaultSlots, createFormKit, nativeControls } from "fokit"

// ---cut---
const kit = createFormKit({
	controls: nativeControls,
})

const customSlots = createDefaultSlots({
	i18n: {
		arrayAdd: "Add item",
	},
})
```

## What Fokit owns

Fokit owns the typed form store, validation lifecycle, generated rendering,
array commands, issue exposure, and native FormData coordination. The same
definition can render with `kit.AutoForm` or be composed manually with
`kit.Form`, `kit.Fields`, and granular hooks.

## What stays yours

Controls stay explicit because value types and FormData behavior are part of
the public form contract. Use `nativeControls` for common HTML controls, compose
custom controls with `defineControl`, and override any structural slot when
your product needs its own markup. `createDefaultSlots()` provides accessible,
unstyled English markup; it is not a theme and it imports no CSS.
