# Examples

Use these examples to inspect complete product workflows and development tools.
All examples use public Form, Please APIs and run without a remote server.

## Design-system integration

- [Material UI with Yup](/examples/mui-yup) — use the official Material UI 9
  preset, its 22 scenario-specific controls, and direct Standard Schema
  validation with Yup.
- [Shadcn with Valibot](/examples/shadcn-valibot) — install an
  application-owned Base UI adapter, exercise all 18 controls, and validate a
  workshop proposal through Standard Schema without Zod.

## Complex product workflows

Each product example owns a complete Standard Schema and a coherent workflow.
It sends typed output through deterministic fake requests in TanStack Query.

- [Research grant application](/examples/research-grant) — conditional
  applicant identity, an asynchronous registry, cascade cleanup, live preview,
  and two-step submission.
- [Creative studio policies](/examples/studio-policies) — two loaded resources,
  cross-section rules, nested policy groups, a movable equipment array, and two
  writes.
- [Makerspace launch wizard](/examples/makerspace-launch) — four form-owned
  stages, address resolution, coordinates, files, gallery rows, capacity
  pricing, four promotions, and three writes.
- [Learning cohort editor](/examples/learning-cohort) — asynchronous title
  suggestions, session and pricing matrices, media, four offer subforms, and
  save-conflict recovery.
- [Membership ladder](/examples/membership-ladder) — four cascading tiers,
  nested benefit arrays, workspace connection, and calendar-assisted pauses.
- [Campaign builder](/examples/campaign-builder) — seven payload variants that
  share audience, schedule, channel, payment, and create-or-edit behavior.

## State and developer workflows

- [History workflow](/examples/history) — navigate committed document groups,
  export a journal, replay it without effects, and validate an import.
- [Persistent draft workflow](/examples/persistence) — restore, observe, save,
  and delete a versioned browser draft.
- [Redux DevTools workflow](/examples/devtools) — inspect committed events,
  restore known local documents, and disconnect the integration without
  stopping the form.

## What to look for

Change a discriminator and watch inactive values leave the form transaction.
Reorder array rows and confirm their state moves with them. Trigger a fake
request and keep editing while request state remains outside Form, Please.

In the History example, edit the title and navigate the retained groups. In the
Persistence example, save a note and reload the page. In the DevTools example,
inspect committed events and restore an earlier document.

The examples make ownership visible. Form, Please owns editable values and
form semantics. The optional features own their document history, draft
encoding, or diagnostic connection. TanStack Query owns remote lifecycle and
cache state.
