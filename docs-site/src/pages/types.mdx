# TypeScript

## Schema types

- `StandardSchema<Input, Output>` describes the validation contract.
- `FormInput<Schema>` is the editable TanStack Form value.
- `FormOutput<Schema>` is the parsed submit value.

## Paths

- `FieldPath<Value>` aliases TanStack Form `DeepKeys<Value>`.
- `PathValue<Value, Path>` aliases TanStack Form `DeepValue<Value, Path>`.
- `ArrayFieldPath<Value>` keeps only paths whose values are arrays.

## Main runtime types

- `FormKit` describes one controls, slots, grid, and context snapshot.
- `FormDefinition` describes a normalized fixed definition.
- `FormBinding` is the thin "Form, Please" wrapper around `form.api`.
- `UseFormOptions`, `FormProps`, and `AutoFormProps` configure React usage.

## UI and control types

`ControlDefinition`, `ControlProps`, `UiNode`, `FieldNode`, `SectionNode`, and
`ArrayNode` keep paths, values, options, context, slot options, and array
defaults aligned. `DeepReadonly`, `UiResolver`, `UiResolverValues`, and
`UiResolverDetails` describe synchronous derived UI.
