# TanStack Form runtime

Use `form-please/tanstack` when you want Form, Please definitions and design
system contracts with TanStack Form as the state manager. This experimental
entry is separate from the standard Form, Please runtime.

Install the optional peer dependency:

```bash
npm install form-please @tanstack/react-form zod
```

## Try the complete flow

Change the format and inspect the conditional room and stream fields. Add or
reorder speakers. Submit invalid values to start change revalidation. The live
panel reads TanStack state through `kit.tf.Subscribe`.

<TanStackFormDemo />

## API boundary

- Form, Please components remain on `kit.Form`, `kit.Fields`, `kit.Submit`, and
  `kit.AutoForm`.
- Context-bound TanStack components use the `kit.tf` namespace.
- `kit.useForm` creates the form and returns the Form, Please integration
  instance.
- Standard Schema validates input. The submit callback receives parsed output.
- This runtime does not provide FormData, server adapters, persistence,
  history, or the standard Form, Please DevTools protocol.
