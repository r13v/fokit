# Learning cohort editor

This form combines a remotely suggested public identity with several dependent
collections: session formats, non-overlapping price bands, media references,
and four distinct enrollment offers. A server-style title conflict returns to
the exact field that can resolve it.

## Try the complete flow

Edit the title and choose one of the query-backed suggestions. Reorder session
formats, create an overlapping price range, or enable an offer without its
dependent values. To exercise conflict recovery, enter `Reserved cohort` and
save; the fake API places a server issue on the title while preserving the rest
of the draft.

## What this form stresses

- A loaded edit baseline and a query keyed by a live field value.
- Render-node controls that update typed Form, Please paths.
- Two reorderable configuration arrays plus media and a native file.
- Cross-row price validation rather than row-local validation only.
- Four offer subforms composed from one typed object-scoped fragment.
- `queryToResource` projecting query-owned title suggestions into exhaustive
  pending, success, refresh, and error presentation.
- Three sequential resource mutations.
- Mapping a typed conflict back into the Form, Please server-error lifecycle.
