# History workflow

This example adds user-facing document navigation to one form. The form keeps
its normal validation and submission behavior while the History feature stores
committed document groups.

## Try the workflow

1. Change **Title** to `Second draft`.
2. Select **Undo**.
3. Select **Redo**.
4. Select **Export**.
5. Change the title again.
6. Select **Import** to restore the exported journal position.
7. Select **Clear history** to keep only the current document.

<HistoryDemo />

The position output changes after each retained group. The form stays active
when an operation is unavailable or an imported value is invalid.

## What this example shows

- `createHistoryMiddleware` adds one History feature during form creation.
- `historyFeature.handle(form)` returns the handle for that exact form.
- `subscribe()` and `getSnapshot()` expose navigation state to React.
- `undo()`, `redo()`, and `seek()` submit live restore transactions.
- `export()` returns an immutable journal.
- `replayJournal()` calculates a document without changing the live form.
- `import()` validates untrusted journal data before it restores a document.
