# Redux DevTools workflow

This example connects a live article editor to the Redux DevTools browser
extension. It uses the public `form-please/devtools` entry point and does not
add Redux to the application.

## Try the workflow

1. Open Redux DevTools in your browser.
2. Select the **Article editor** connection.
3. Change the title more than once.
4. Select an earlier event to restore its form document.
5. Select **Disconnect DevTools** to stop the integration.

<DevToolsDemo />

The form continues to work when the extension is absent or after you disconnect
the integration.

## What this example shows

- `createDevToolsMiddleware` connects one form to the extension.
- The monitor receives finalized form events and visible document state.
- Time travel restores only documents that the local integration still knows.
- DevTools failures do not stop form updates.
- `disconnect()` removes the listener without disposing the form.
